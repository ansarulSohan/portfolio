# Portfolio — G.M. Ansarul Kabir

Personal portfolio being rebuilt as a Next.js app with an admin CMS backed by MongoDB Atlas, deployed on Coolify.
See [`docs/REBUILD_PLAN.md`](docs/REBUILD_PLAN.md) for the full plan and phase status.

## Commands

```bash
pnpm install
cp .env.example .env.local   # fill in values
pnpm dev                     # http://localhost:3000
pnpm build && pnpm start     # production build + server
pnpm lint
pnpm typecheck
```
